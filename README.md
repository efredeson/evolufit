# EvoluFit 🐱💚

Aplicativo web responsivo com treinos em casa, caminhadas, alimentação e acompanhamento pessoal de evolução.

Projeto inicial em desenvolvimento. Interface branca e verde com mascote gato cartoon.

**Atenção:** registros do protótipo ficam no navegador; não há login, sincronização online ou notificações confiáveis com o site fechado. Dados de saúde e fotos devem permanecer privados.
